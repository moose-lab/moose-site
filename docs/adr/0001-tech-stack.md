# ADR-0001：Moose 个人网站技术栈

**状态：** Accepted（2026-10-05，站长未另行指定，按推荐方案执行）
**日期：** 2026-10-05
**决策人：** Moose（站长）

## 背景

- 个人博客，一个人写，读者以中文为主；内容是长文、碎碎念、训练日志、小红书笔记四种，Feed 是核心。
- 站长是 AI 科学家，开发和审计交给 Claude Code + superpowers；站长自己不想维护服务器和数据库。
- 需要网页后台（手机也能发），也希望能让 Claude Code 直接写内容。
- 要先尽快上线，再根据真实效果迭代前端；评论、订阅、专栏、AI 功能后续再加。
- 视觉是「草稿本涂鸦」风格，大量自定义 CSS，几乎不需要客户端交互。

## 决策

Astro 7（静态输出）+ Git 仓库 Markdown 内容 + Pages CMS 后台 + Cloudflare Workers 静态资源托管。

## 方案比较

### 框架

| 方案 | 复杂度 | 成本 | 可扩展性 | 结论 |
|---|---|---|---|---|
| **Astro 7** | 低 | 免费 | 静态为主，可按路由开按需渲染；Cloudflare 维护 | ✅ 选用 |
| Next.js | 中高 | 免费 | 强，但 React 运行时对内容站是负担 | 过重 |
| Hugo | 低 | 免费 | 模板语言写复杂组件和测试不方便 | 不选 |
| WordPress / Ghost | 中 | 需要服务器或付费托管 | 插件 / 会员强，但深度定制涂鸦主题成本高 | 不选 |

### 后台 / 内容管理

| 方案 | 运维 | 和站点的耦合 | 主要风险 | 结论 |
|---|---|---|---|---|
| **Pages CMS（托管版）** | 零 | 只有一个 `.pages.yml`，站点保持纯静态 | 后台在第三方域名；不支持对象数组（训练日志用字符串列表规避） | ✅ 默认 |
| Keystatic（GitHub 模式） | 低 | 站内 `/keystatic`，需要 Cloudflare 适配器和 React | 社区小、更新节奏慢，需验证 Astro 7 兼容性 | 备选 |
| Decap / Sveltia | 低 | 需要自己部署 GitHub OAuth 代理 | 多一个要维护的组件 | 不选 |
| EmDash（Cloudflare） | 中 | 内容存 D1，页面全部服务端渲染 | 仍是 beta；内容不在 Git 里 | 观察，暂不选 |
| 只用 Claude Code / 编辑器写 Markdown | 零 | 无 | 手机上发碎碎念不方便 | 作为补充通道保留 |

### 托管

| 方案 | 成本 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **Cloudflare Workers（静态资源）** | 免费额度充足 | Astro 官方推荐路径；后续 D1 / R2 / KV / Workers AI 都在同一平台 | 自定义域名需要 DNS 托管到 Cloudflare | ✅ 选用 |
| Cloudflare Pages | 免费 | 配置更简单 | Cloudflare 对新项目推荐 Workers | 不选 |
| Vercel | 免费额度 | 体验好 | 默认 `*.vercel.app` 域名在中国大陆访问经常受限；扩展能力需要接外部服务 | 不选 |
| 国内云 + 备案 | 低 | 大陆访问快 | 需要 ICP 备案，周期长 | P2 视读者分布再定 |

## 取舍分析

- 选 Git 内容而不是数据库 CMS：放弃了「随时改、即时生效」的动态感（每次发布要重新构建，约 1–3 分钟），换来零运维、内容可版本化，以及后台随时可换。对个人博客的发布频率来说，这个延迟可以接受。
- 选 Pages CMS 而不是 Keystatic：放弃了站内后台的一体感，换来站点纯静态、和 Astro 版本完全解耦。如果站长更看重「后台在自己域名下」，可以改选 Keystatic，内容格式不受影响。
- 选 Cloudflare：和 Astro 的官方路径一致，并且以后加评论、订阅、AI 问答时，D1 / R2 / Workers AI 都在同一个平台上，不需要再引入新供应商。

## 影响

- 更容易：发布（后台或 Claude Code）、回滚（git revert）、迁移、加按需渲染的动态功能。
- 更难：真正实时的内容（如直播式更新）需要额外设计；Pages CMS 不支持对象数组，复杂结构化内容要在 schema 设计上让步。
- 之后要回头看：Q1 读者分布（是否备案）、Keystatic / EmDash 的成熟度、Pagefind 中文搜索效果。
